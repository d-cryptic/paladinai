## 2. paladin-hub gRPC Proto

```proto
syntax = "proto3";
package paladin.hub.v1;

import "google/protobuf/struct.proto";

service HubService {
  rpc DiscoverTools(DiscoverRequest)   returns (DiscoverResponse);
  rpc RegisterTool(RegisterRequest)   returns (RegisterResponse);
  rpc ListTools(ListToolsRequest)     returns (ListToolsResponse);
  rpc HealthCheck(HealthRequest)      returns (HealthResponse);
}

message DiscoverRequest {
  string intent     = 1;
  string tenant_id  = 2;
  int32  top_k      = 3;
}

message ToolSchema {
  string                    name         = 1;
  string                    description  = 2;  // max 100 chars
  google.protobuf.Struct    input_schema = 3;
  string                    mcp_endpoint = 4;  // e.g. grpc://mcp-datadog.paladin:50051
  string                    use_when         = 5;
  string                    do_not_use_when  = 6;
}

message DiscoverResponse {
  repeated ToolSchema tools = 1;
}

message RegisterRequest {
  string integration_name = 1;
  string tenant_id        = 2;
  repeated ToolSchema tools = 3;
}

message RegisterResponse {
  repeated string tool_ids = 1;
}

message ListToolsRequest {
  string tenant_id = 1;
  string category  = 2;  // optional filter
  string name_prefix = 3;
}

message ToolMeta {
  string tool_id        = 1;
  string name           = 2;
  string integration    = 3;
  string category       = 4;
  string mcp_endpoint   = 5;
}

message ListToolsResponse {
  repeated ToolMeta tools = 1;
}

message HealthRequest {}

message ToolHealth {
  string tool_id  = 1;
  bool   healthy  = 2;
  string reason   = 3;
}

message HealthResponse {
  repeated ToolHealth tools = 1;
}
```

**Storage:**
- Qdrant: tool description embeddings (cosine) → semantic DiscoverTools
- PG table `tenant_integration_permissions(tenant_id, integration_name, enabled_at)` → ListTools filter

## 3. MCP Server Template

```go
// pkg/mcp/server.go — base for every integration MCP server

type MCPServer struct {
    name        string
    tools       map[string]ToolHandler
    vault       *vault.Client
    rateLimiter *rate.Limiter  // per-tenant, keyed by tenant_id
    hubConn     *grpc.ClientConn
}

type ToolHandler func(ctx context.Context, tenantID string, params json.RawMessage) (json.RawMessage, error)

func NewMCPServer(name string, vault *vault.Client, hubAddr string) *MCPServer

// Startup sequence
func (s *MCPServer) Start(port int) error {
    s.registerTools()         // calls hub.RegisterTool for each tool
    s.startHealthEndpoint()   // GET /healthz → 200
    return s.serveGRPC(port)
}

// Every tool call goes through this
func (s *MCPServer) CallTool(ctx context.Context, req *mcp.CallToolRequest) (*mcp.CallToolResponse, error) {
    tenantID := extractTenant(ctx)          // from gRPC metadata
    creds, err := s.vault.GetSecret(        // dynamic credentials per tenant
        fmt.Sprintf("secret/tenants/%s/%s", tenantID, s.name),
    )
    if err != nil { return nil, ErrUnauthorized }

    if !s.rateLimiter.Allow() {             // per-tenant bucket
        return nil, ErrRateLimited
    }

    handler, ok := s.tools[req.ToolName]
    if !ok { return nil, ErrUnknownTool }

    result, err := handler(ctx, tenantID, req.Params)
    if err != nil { return nil, err }

    logToolCall(ctx, tenantID, s.name, req.ToolName, req.Params) // → ClickHouse
    return &mcp.CallToolResponse{Content: result}, nil
}

// Tool registration — description must include use_when + do_not_use_when
func (s *MCPServer) RegisterTool(t ToolSchema) {
    s.tools[t.Name] = t.Handler
    // pushed to hub on Start()
}
```

```
         ▼
┌─────────────────┐

         │ POST /api/v1/integrations/enable
         ▼
┌─────────────────────┐
│  paladin-api (Go)   │  validates payload, checks tenant permissions
└────────┬────────────┘
         │ validate creds (test API call to Datadog)
         ▼
┌─────────────────────┐
│   Vault (KV v2)     │  stores api_key + app_key under
└────────┬────────────┘  secret/tenants/{tenant_id}/datadog
         │ patch ConfigMap → paladin-collector
         ▼
┌───────────────────────────┐
│  paladin-collector (OTel) │  hot-reload via SIGHUP, activates datadogreceiver
└────────┬──────────────────┘
         │ Helm install mcp-datadog chart (or kubectl apply)
         ▼
┌──────────────────────┐
│  mcp-datadog pod     │  starts, registers tools → paladin-hub
└────────┬─────────────┘
         │ RegisterTool() gRPC calls
         ▼
┌──────────────────────┐
│   paladin-hub        │  stores tool embeddings in Qdrant,
└────────┬─────────────┘  updates PG tenant_integration_permissions
         │ hub.HealthCheck()
         ▼
┌──────────────────────────────┐
│  paladin integrations doctor │  confirms receiver ✓, MCP ✓, hub ✓
└──────────────────────────────┘
```

## 6. AlertEnvelope Normalization

```go
type AlertEnvelope struct {
    ID          string            // deduplication key
    Source      string            // "alertmanager" | "datadog" | "cloudwatch" | "pagerduty" | "webhook"
    TenantID    string
    Severity    string            // "critical" | "high" | "medium" | "low" | "info"
    Title       string
    Description string
    Labels      map[string]string
    StartsAt    time.Time
    EndsAt      *time.Time        // nil = still firing
    GeneratorURL string
    RawPayload  json.RawMessage   // original, unmodified
}
```

| Source          | Key Fields Mapped                                                | Normalization Notes                                    |
|-----------------|------------------------------------------------------------------|--------------------------------------------------------|
| Alertmanager    | labels.alertname→Title, annotations.summary→Description, startsAt, endsAt | severity from labels.severity              |
| Datadog         | title, message, priority→Severity, date_happened→StartsAt       | priority: 1=critical,2=high,3=medium,4=low             |
| CloudWatch SNS  | AlarmName→Title, NewStateReason→Description, StateChangeTime    | Severity inferred from AlarmName prefix or default=high|
| PagerDuty       | title, body.details→Description, severity, created_at           | direct mapping; status=resolved sets EndsAt            |
| Custom Webhook  | configurable field mapping in integration.yaml                   | fallback: description=raw JSON if unmatched             |

One Go file per source: `paladin-ingest/normalizer/alertmanager.go`, `datadog.go`, etc.
Router in `paladin-ingest/router.go` matches `Content-Type` + path prefix to normalizer.

## 8. Tool Description Standards

Required fields for every tool registered with paladin-hub:

| Field            | Constraint                  |
|------------------|-----------------------------|
| name             | `integration.tool_name`     |
| description      | ≤ 100 chars, verb-first     |
| use_when         | scenario sentence(s)        |
| do_not_use_when  | anti-pattern sentence(s)    |
| input_schema     | JSON Schema (draft-07)      |
| output_schema    | JSON Schema (draft-07)      |

**Example — `prometheus.query_range`:**

```json
{
  "name": "prometheus.query_range",
  "description": "Execute a PromQL range query and return time-series data.",
  "use_when": "User asks for metric trends, graphs, or values over a time window.",
  "do_not_use_when": "User wants current/instant value only — use prometheus.query instead.",
  "input_schema": {
    "type": "object",
    "required": ["query", "start", "end", "step"],
    "properties": {
      "query": {"type": "string"},
      "start": {"type": "string", "format": "date-time"},
      "end":   {"type": "string", "format": "date-time"},
      "step":  {"type": "string", "description": "e.g. 15s, 1m, 5m"}
    }
  },
  "output_schema": {
    "type": "object",
    "properties": {
      "result_type": {"type": "string"},
      "result": {"type": "array"}
    }
  }
}
```

## 9. Multi-tenant Tool Isolation

**Hub — DiscoverTools:**
```sql
-- filters to tenant's enabled integrations before vector search
SELECT t.tool_id, t.mcp_endpoint
FROM tools t
JOIN tenant_integration_permissions p
  ON t.integration_name = p.integration_name
WHERE p.tenant_id = $1 AND p.enabled = true
```
Qdrant search scoped to returned `tool_id` list via payload filter.

**MCP Server — every call:**
1. Extract `tenant_id` from gRPC metadata header `x-paladin-tenant-id`.
2. Fetch credentials: `vault.KVv2.Get("secret/tenants/{tenant_id}/{integration}")`.
3. Reject if secret missing or tenant_id mismatch.

**Audit log — ClickHouse:**
```sql
CREATE TABLE tool_audit_log (
    ts          DateTime64(3),
    tenant_id   String,
    tool_name   String,
    params_hash String,   -- SHA-256 of params (no PII stored)
    duration_ms UInt32,
    success     Bool
) ENGINE = MergeTree()
ORDER BY (tenant_id, ts);
```
