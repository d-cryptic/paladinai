## 1. Observability Architecture

```
                    ┌─────────────────────────────────────────────┐
                    │             Paladin Services                 │
  paladin-edge      │  OTel SDK (go.opentelemetry.io/otel v1.x)   │
  paladin-agent     │  + opentelemetry-rust (gateway)             │
  paladin-ingest  ──│  Traces + Metrics + Logs                    │
  paladin-hub       │                                             │
  paladin-memory    │                                             │
  paladin-gateway   │                                             │
                    └──────────────────┬──────────────────────────┘
                                       │ OTLP gRPC :4317
                                       ▼
                    ┌──────────────────────────────────────────────┐
                    │         OTel Collector 0.120.x (contrib)     │
                    │  receivers:  otlp (gRPC + HTTP)              │
                    │  processors: batch │ memory_limiter │         │
                    │              resourcedetection │ routing      │
                    └────┬─────────────┬────────────┬─────────────┘
                         │             │            │
              ┌──────────▼──┐  ┌───────▼──┐  ┌────▼────┐
              │ Grafana Tempo│  │  Mimir   │  │  Loki   │
              │  (traces)    │  │ (metrics)│  │  (logs) │
              └──────────────┘  └──────────┘  └─────────┘
                         └──────────────┬────────────────┘
                                        ▼
                              ┌──────────────────┐
                              │   Grafana UI     │
                              └──────────────────┘

  LLM / agent spans ──► prod tenants ──► LangSmith (OTLP HTTP)
                    └──► EU tenants  ──► Langfuse self-hosted (GDPR — no US egress)

  Cost events (direct write, bypasses OTel)
              └──────────────────────────► ClickHouse 24.x
                                           llm_cost_events
                                           agent_latency_events
```

**Key decisions:**

| Decision | Choice | Reason |
|---|---|---|
| Cost path | Direct ClickHouse write | Keeps billing off observability critical path |
| Agent tracing | OTel → LangSmith/Langfuse | Replay, diffing, prompt versioning not in Tempo |
| EU isolation | Langfuse self-hosted only | GDPR — zero data egress to US SaaS |
| Semconv | Dual-emit during transition | GenAI semconv experimental until GA |

## 2. OTel Instrumentation Per Service

**Sampling baseline:** P1 = 100%, P2 = 25%, P3 = 10%, health checks = 0% (filtered at collector).

| Service | Traced operations | Key extra attributes | Auto-instrumentation packages |
|---|---|---|---|
| **paladin-edge** | WebSocket lifecycle, HTTP routing, auth, NATS publish | `paladin.connection_id`, `paladin.auth_method` | `otelhttp`, `otelmux` |
| **paladin-agent** | Incident root span, every Eino node, LLM calls (GenAI semconv), tool calls, checkpoint writes | `paladin.incident_id`, `paladin.eino_node`, `paladin.llm_tier`, all `gen_ai.*` attrs | `opentelemetry-instrumentation-anthropic`, `opentelemetry-instrumentation-openai`, `otelhttp` |
| **paladin-ingest** | Webhook receive, normalisation pipeline, schema validation, NATS publish | `paladin.integration_type`, `paladin.normalization_result` | `otelhttp` |
| **paladin-hub** | Tool discovery scan, registration, MCP tool call proxy, health checks | `paladin.tool_name`, `paladin.tool_provider`, `paladin.mcp_server_id` | `otelhttp` |
| **paladin-memory** | Vector search (Qdrant), episode read/write, consolidation job, embedding request | `paladin.memory_op`, `paladin.query_type`, `db.system` | `otelhttp` (Qdrant), `otelsql` (PG) |
| **paladin-gateway** | Inbound proxy request, provider selection, outbound LLM call, cache lookup/write, circuit breaker transitions, ClickHouse cost write | `paladin.llm_tier`, `paladin.cache_hit`, `paladin.circuit_breaker_state`, `gen_ai.*` | `opentelemetry` + `opentelemetry-otlp` Rust crates |

All services include: `paladin.tenant_id` on every span.

## 5. ClickHouse Schemas for Cost and Billing

Cost events bypass OTel. paladin-gateway writes directly to ClickHouse at LLM call completion.

### 5.1 llm_cost_events

```sql
CREATE TABLE llm_cost_events
(
    event_id        UUID,
    tenant_id       String,
    incident_id     String,
    trace_id        String,         -- links back to OTel trace
    span_id         String,
    model           String,
    provider        String,
    llm_tier        String,
    input_tokens    UInt32,
    output_tokens   UInt32,
    cached_tokens   UInt32,
    cost_usd        Decimal(10, 6), -- computed at write time
    agent_type      String,
    region          String,         -- "us" | "eu" | "apac"
    timestamp       DateTime64(3)
)
ENGINE = MergeTree()
PARTITION BY toYYYYMM(timestamp)
ORDER BY (tenant_id, timestamp);
```

### 5.2 agent_latency_events

```sql
CREATE TABLE agent_latency_events
(
    event_id        UUID,
    tenant_id       String,
    incident_id     String,
    trace_id        String,
    agent_type      String,
    priority        String,    -- "P1" | "P2" | "P3"
    eino_node       String,
    step_name       String,
    duration_ms     UInt32,
    llm_calls       UInt16,
    tool_calls      UInt16,
    input_tokens    UInt32,
    output_tokens   UInt32,
    status          String,    -- "success" | "error" | "timeout"
    timestamp       DateTime64(3)
)
ENGINE = MergeTree()
PARTITION BY toYYYYMM(timestamp)
ORDER BY (tenant_id, incident_id, timestamp);
```

### 5.3 Cost computation

```
cost_usd = (input_tokens  × price_in)
         + (output_tokens × price_out)
         - (cached_tokens × 0.9 × price_in)

# Anthropic prompt cache: cached tokens billed at ~10% of normal input price.
```

Model prices stored in PostgreSQL `model_prices` table (never hardcoded). paladin-gateway loads at startup, refreshes every 5 min.

```sql
CREATE TABLE model_prices (
    model          TEXT PRIMARY KEY,
    provider       TEXT NOT NULL,
    price_in       NUMERIC(12, 8) NOT NULL,  -- USD per input token
    price_out      NUMERIC(12, 8) NOT NULL,  -- USD per output token
    effective_from TIMESTAMPTZ NOT NULL,
    effective_to   TIMESTAMPTZ,              -- NULL = currently active
    notes          TEXT
);
```

## 6. LLM-Level Tracing — Agent Trajectory

### Eino node → OTel span mapping

Each Eino graph node = one OTel span. Incident span is root; node spans are children.

```
incident (root span)
│   paladin.incident_id, paladin.tenant_id, paladin.agent_type
│
├── eino:classify
│     ├── event: llm_call_start  { model, est_tokens }
│     ├── gen_ai:chat            (GenAI semconv child span)
│     │     ├── event: tool_call_start  { tool_name }
│     │     └── event: tool_call_end    { result_bytes }
│     └── event: checkpoint_written    { key, step }
│
└── eino:rca_plan
      └── gen_ai:chat
            ├── event: tool_call_start / tool_call_end  (per tool)
            └── event: llm_call_end  { tokens, finish_reason }
```

### Routing: LangSmith vs Langfuse

paladin-agent sets `paladin.tenant_region` as a resource attribute. The OTel Collector's `routing` connector fans out:

```
tenant.region = "us"  →  traces/us_langsmith  (LangSmith OTLP HTTP)
tenant.region = "eu"  →  traces/eu_langfuse   (Langfuse self-hosted — no US egress)
```

### Priority-based sampler (Go)

```go
type IncidentPrioritySampler struct{}

func (s IncidentPrioritySampler) ShouldSample(p sdktrace.SamplingParameters) sdktrace.SamplingResult {
    switch attributeValue(p.Attributes, "paladin.incident_priority") {
    case "P1":
        return sdktrace.AlwaysSample().ShouldSample(p)   // 100%
    case "P2":
        return probabilistic(0.25).ShouldSample(p)       // 25%
    default:
        return probabilistic(0.10).ShouldSample(p)       // 10%
    }
}
```

## 8. Alerting Rules

```yaml
groups:
  - name: paladin.nats
    rules:
      - alert: NATSAgentWorkerBacklog
        expr: paladin_nats_pending_messages{stream="incidents"} > 100
        for: 5m
        labels: { severity: warning }
        annotations:
          summary: "{{ $value }} pending messages in incidents stream"
          runbook: "https://docs.paladinai.dev/runbooks/nats-backlog"

  - name: paladin.llm
    rules:
      - alert: LLMErrorRateHigh
        expr: >
          (rate(paladin_llm_calls_total{status=~"error|5.."}[5m])
           / rate(paladin_llm_calls_total[5m])) > 0.20
        for: 3m
        labels: { severity: critical }
        annotations:
          summary: "LLM error rate {{ $value | humanizePercentage }} tier={{ $labels.tier }}"
          runbook: "https://docs.paladinai.dev/runbooks/llm-errors"

      - alert: CircuitBreakerOpen
        expr: paladin_gateway_circuit_breaker_state == 1
        for: 1m
        labels: { severity: warning }
        annotations:
          summary: "Circuit breaker OPEN: {{ $labels.provider }}/{{ $labels.model }}"

  - name: paladin.sla
    rules:
      - alert: TriageLatencySLABreach
        expr: >
          histogram_quantile(0.95,
            rate(paladin_agent_duration_seconds_bucket{agent_type="triage"}[10m])) > 10
        for: 5m
        labels: { severity: critical }
        annotations:
          summary: "Triage P95={{ $value }}s > 10s SLA"
          runbook: "https://docs.paladinai.dev/runbooks/triage-latency"

  - name: paladin.memory
    rules:
      - alert: QdrantQueryLatencyHigh
        expr: >
          histogram_quantile(0.95,
            rate(paladin_memory_retrieval_latency_seconds_bucket{query_type="semantic"}[5m])) > 0.5
        for: 5m
        labels: { severity: warning }
        annotations:
          summary: "Vector search P95={{ $value }}s > 500ms"

      - alert: MemoryConsolidationStale
        expr: (time() - paladin_memory_consolidation_last_run_timestamp) > 691200
        for: 0m
        labels: { severity: warning }
        annotations:
          summary: "Consolidation not run >8d for {{ $labels.tenant_id }}"

  - name: paladin.billing
    rules:
      - alert: TenantBudgetSoftLimit
        expr: >
          (paladin_gateway_cost_usd_total
           / on(tenant_id) group_left paladin_tenant_monthly_budget_usd) > 0.80
        for: 0m
        labels: { severity: info }
        annotations:
          summary: "{{ $labels.tenant_id }} >80% of monthly budget"
```

## 9. OTel Collector Pipeline Config

Pinned: `otelcol-contrib:0.120.x`

```yaml
receivers:
  otlp:
    protocols:
      grpc: { endpoint: 0.0.0.0:4317 }
      http:  { endpoint: 0.0.0.0:4318 }

processors:
  batch:
    timeout: 5s
    send_batch_size: 1000
  memory_limiter:
    check_interval: 1s
    limit_mib: 512
    spike_limit_mib: 128
  resourcedetection:
    detectors: [env, system]
    timeout: 5s
  filter/drop_healthchecks:
    traces:
      span:
        - 'attributes["http.route"] == "/health" or attributes["http.route"] == "/ready"'

connectors:
  routing:
    default_pipelines: [traces/default]
    error_mode: ignore
    table:
      - statement: route() where resource.attributes["paladin.tenant_region"] == "eu"
        pipelines: [traces/eu_langfuse]
      - statement: route() where resource.attributes["paladin.tenant_region"] == "us"
        pipelines: [traces/us_langsmith]

exporters:
  otlp/tempo:
    endpoint: tempo:4317
    tls: { insecure: true }
  prometheusremotewrite/mimir:
    endpoint: http://mimir:9009/api/v1/push
    tls: { insecure: true }
  loki:
    endpoint: http://loki:3100/loki/api/v1/push
  otlphttp/langsmith:
    endpoint: https://api.smith.langchain.com/otel
    headers: { x-api-key: "${LANGSMITH_API_KEY}" }
  otlphttp/langfuse_eu:
    endpoint: http://langfuse-eu.internal:3000/api/public/otel
    headers: { authorization: "Basic ${LANGFUSE_EU_BASIC_AUTH}" }

service:
  pipelines:
    traces/default:
      receivers:  [otlp]
      processors: [memory_limiter, batch, resourcedetection, filter/drop_healthchecks]
      exporters:  [otlp/tempo, routing]

    traces/us_langsmith:
      receivers:  [routing]
      processors: [batch]
      exporters:  [otlphttp/langsmith]

    traces/eu_langfuse:
      receivers:  [routing]
      processors: [batch]
      exporters:  [otlphttp/langfuse_eu]

    metrics:
      receivers:  [otlp]
      processors: [memory_limiter, batch, resourcedetection]
      exporters:  [prometheusremotewrite/mimir]

    logs:
      receivers:  [otlp]
      processors: [memory_limiter, batch, resourcedetection]
      exporters:  [loki]
```

**EU-region override:** disable `otlphttp/langsmith`, remove `traces/us_langsmith` pipeline, route all traces to `traces/eu_langfuse` only.

**Collector sizing:**

| Environment | CPU | Memory |
|---|---|---|
| Dev | 0.25 vCPU | 256 MiB |
| Prod (per region) | 2 vCPU, 2 replicas | 2 GiB |
| EU prod (isolated) | 2 vCPU, 2 replicas | 2 GiB |
