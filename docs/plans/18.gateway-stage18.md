```
     │         │         │         │
     ▼         ▼         ▼         ▼
Anthropic  OpenRouter  Groq     vLLM
           (Qwen/       (Llama)  (local)
           DeepSeek/
           Kimi)

Circuit Breaker States (per provider):
  Closed ──[≥50% errors/60s]──▶ Open
  Open   ──[30s cooldown]─────▶ HalfOpen
  HalfOpen──[3 probe OK]──────▶ Closed
  HalfOpen──[probe fail]──────▶ Open
```

## 4. Circuit Breaker (Rust)

```rust
use std::time::{Duration, Instant};
use tokio::sync::RwLock;

#[derive(Debug, Clone, PartialEq)]
enum CbState {
    Closed,
    Open { until: Instant },
    HalfOpen { probes_ok: u8 },
}

#[derive(Debug)]
struct CircuitBreaker {
    state:        RwLock<CbState>,
    window:       Duration,          // 60s
    error_thresh: f64,               // 0.50
    cooldown:     Duration,          // 30s
    probe_target: u8,                // 3
    // sliding window counters
    requests:     RwLock<VecDeque<(Instant, bool)>>,
}

impl CircuitBreaker {
    async fn allow(&self) -> bool {
        let state = self.state.read().await;
        match &*state {
            CbState::Closed => true,
            CbState::Open { until } => Instant::now() >= *until,
            CbState::HalfOpen { .. } => true, // one probe at a time
        }
    }

    async fn record(&self, success: bool) {
        let mut win = self.requests.write().await;
        win.push_back((Instant::now(), success));
        let cutoff = Instant::now() - self.window;
        win.retain(|(t, _)| *t >= cutoff);

        let total = win.len() as f64;
        let errors = win.iter().filter(|(_, ok)| !ok).count() as f64;
        let rate   = if total > 0.0 { errors / total } else { 0.0 };

        let mut state = self.state.write().await;
        match &*state {
            CbState::Closed if rate >= self.error_thresh => {
                *state = CbState::Open {
                    until: Instant::now() + self.cooldown,
                };
            }
            CbState::HalfOpen { probes_ok } if success => {
                let n = probes_ok + 1;
                if n >= self.probe_target {
                    *state = CbState::Closed;
                } else {
                    *state = CbState::HalfOpen { probes_ok: n };
                }
            }
            CbState::HalfOpen { .. } if !success => {
                *state = CbState::Open {
                    until: Instant::now() + self.cooldown,
                };
            }
            CbState::Open { until } if Instant::now() >= *until => {
                *state = CbState::HalfOpen { probes_ok: 0 };
            }
            _ => {}
        }
    }
}
```

## 5. Fallback Chain

```
resolve_alias("smart")
  → providers: [deepseek(60%), claude(40%)]

attempt 1: weighted_pick() → deepseek/deepseek-r1
  → CB open? skip
  → call → 429 Too Many Requests
  → record failure
  → log: {provider: "openrouter", reason: "429", attempt: 1}

attempt 2: next available → anthropic/claude-sonnet-4-5
  → CB closed? proceed
  → call → 200 OK
  → return response

if attempt 2 also fails:
  → return 503 Service Unavailable
  → header: Retry-After: 30
  → body: {"error":{"code":"ALL_PROVIDERS_FAILED","message":"..."}}

ClickHouse log record (async, fire-and-forget):
{
  tenant_id, request_id, alias,
  provider, model, failure_reason,
  fallback_used: bool, latency_ms,
  timestamp
}
```

Max fallback attempts: 2 (configurable). Skips same provider twice. Budget-exhausted 429 → no fallback, immediate 429 upstream.

## 6. Semantic Cache

```
Config flag: cache.enabled = true

Flow:
  1. Embed query via BGE-M3 (POST /v1/embeddings → fast alias)
  2. HNSW search in Valkey (vector module):
       VSIM cache:{tenant_id} ELE query_vec WITHSCORES COUNT 1
  3. if score ≥ 0.92:
       → X-Cache: HIT
       → return cached completion JSON
  4. else:
       → forward to provider
       → on response: store in Valkey
           HSET cache:{tenant_id}:{hash} data <json>
           EXPIRE cache:{tenant_id}:{hash} 21600   # 6h TTL
           VADD  cache:{tenant_id} query_vec <hash>

Namespace: cache:{tenant_id} — tenants never share cache entries.
TTL: 6 hours (21600s).
Embedding cost: ~0.001s latency, negligible token cost (BGE-M3 local).
Cache eviction: LRU + TTL, Valkey maxmemory-policy allkeys-lru.
Bypass: X-No-Cache: 1 header skips lookup and store.
```

## 7. Cost Tracking

```rust
// Price table in gateway.toml
// [pricing."qwen/qwen3-72b"]
// input_per_1m  = 0.40   # USD
// output_per_1m = 1.20

async fn track_cost(tenant_id: &str, model: &str, usage: &Usage) {
    let price  = PRICE_TABLE.get(model).unwrap_or(&DEFAULT_PRICE);
    let cost   = (usage.prompt_tokens as f64 / 1_000_000.0) * price.input_per_1m
               + (usage.completion_tokens as f64 / 1_000_000.0) * price.output_per_1m;

    // fire-and-forget: do not await, do not block response
    tokio::spawn(async move {
        CH_CLIENT.execute(
            "INSERT INTO gateway_costs VALUES (?,?,?,?,?,?,?)",
            &[tenant_id, model, usage.prompt_tokens,
              usage.completion_tokens, cost, provider, now_utc()],
        ).await.ok();

        // Budget enforcement (read from Redis budget cache)
        let spent = redis::incrbyfloat(&format!("budget:{tenant_id}"), cost).await;
        if spent > tenant_budget_limit(tenant_id) {
            redis::set(&format!("budget_exceeded:{tenant_id}"), 1).await;
        }
    });
}

// Per-request response headers
X-Cost-USD: 0.000420
X-Tokens-Input: 512
X-Tokens-Output: 128

// Budget gate (checked before forwarding to provider)
if redis::exists(&format!("budget_exceeded:{tenant_id}")) {
    return 429 { "error": { "code": "BUDGET_EXHAUSTED" } }
}
```

## 8. BYOK (Bring Your Own Key)

```
Request header: X-Tenant-ID: tenant-abc

Key resolution order:
  1. Check Vault: secret/gateway/tenants/{tenant_id}/{provider}
     → if found: use tenant key (isolated quota, their rate limits)
  2. else: use platform key (shared quota, shared rate limits)

Vault fetch (cached in process memory 5 min, refreshed on 401):
  vault_client.read(
    path: "secret/gateway/tenants/{tenant_id}/openrouter"
  ) → { "api_key": "sk-or-v1-..." }

Isolation guarantees:
  - Tenant key → billed to tenant's OpenRouter/Anthropic account
  - Rate limits enforced per-key by provider (not shared with platform)
  - No cross-tenant key leakage (Vault policy: read own path only)

Vault sidecar: agent-injector annotates gateway pod:
  vault.hashicorp.com/agent-inject: "true"
  vault.hashicorp.com/role: "paladin-gateway"
```
