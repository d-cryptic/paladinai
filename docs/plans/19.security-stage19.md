## 2. Input Sanitization

**Owner:** `paladin-ingest`  
**Rule:** Sanitization is destructive (modify in place). Never drop alerts; always publish sanitized form.

### Sanitization Rules

| Field | Max Length | Transforms Applied |
|---|---|---|
| `alert_name` | 256 chars | Strip HTML, truncate |
| `description` | 4096 chars | Strip HTML/script, detect prompt injection, truncate |
| `labels.*` | 512 chars each | Strip HTML, reject if contains URL pattern |
| `annotations.*` | 2048 chars each | Strip HTML/script, detect prompt injection, truncate |
| `runbook_url` | 2048 chars | Validate URL scheme = https, allowlisted domain only |

### Prompt Injection Detection Patterns

```
(?i)(ignore previous|disregard above|system:|<system>|you are now|
     forget your instructions|jailbreak|DAN mode|developer mode|
     \bACT AS\b|\bPRETEND\b)
```

Matched content → replaced with `[REDACTED:injection-pattern]`. Event logged to ClickHouse `security_sanitization_events`.

### Go Code Sketch

```go
// paladin-ingest/internal/sanitize/sanitize.go

type SanitizationEvent struct {
    AlertID   string
    TenantID  string
    Field     string
    Original  string // hash only — not full value
    Action    string // "truncated" | "html-stripped" | "injection-redacted"
    Timestamp time.Time
}

var injectionRe = regexp.MustCompile(`(?i)(ignore previous|disregard above|` +
    `system:|<system>|you are now|forget your instructions|jailbreak|` +
    `DAN mode|developer mode|\bACT AS\b|\bPRETEND\b)`)

var htmlRe = regexp.MustCompile(`<[^>]+>|&[a-z]+;`)

func sanitize(env AlertEnvelope) (AlertEnvelope, []SanitizationEvent) {
    var events []SanitizationEvent
    env.AlertName, events = sanitizeField(env.AlertName, "alert_name", 256, events)
    env.Description, events = sanitizeField(env.Description, "description", 4096, events)
    for k, v := range env.Labels {
        env.Labels[k], events = sanitizeField(v, "labels."+k, 512, events)
    }
    return env, events
}

func sanitizeField(val, field string, maxLen int, events []SanitizationEvent) (string, []SanitizationEvent) {
    orig := val
    val = htmlRe.ReplaceAllString(val, "")
    val = injectionRe.ReplaceAllString(val, "[REDACTED:injection-pattern]")
    if len(val) > maxLen {
        val = val[:maxLen]
    }
    if val != orig {
        events = append(events, SanitizationEvent{Field: field, Action: "modified"})
    }
    return val, events
}
```

## 3. mTLS & Network Security

### Service-to-Service mTLS Matrix

| From | To | mTLS | Notes |
|---|---|---|---|
| paladin-collector | paladin-ingest | Yes — Linkerd + client cert pinned to tenant | Extra: client cert CN = tenant_id |
| paladin-ingest | NATS | TLS 1.3 + nkeys per-tenant | No plain TCP |
| paladin-edge | paladin-hub | Linkerd mTLS (automatic) | |
| paladin-hub | PostgreSQL | TLS 1.3 + Vault dynamic cert | Vault-issued short-lived cert |
| paladin-hub | Qdrant | Linkerd mTLS | Qdrant in-cluster only |
| paladin-gateway | LLM Providers | TLS 1.3, system CA bundle | Certificate pinning on critical endpoints |
| MCP servers | Integration APIs | TLS 1.3 + allowlist | See §6 |

### Rules

- No plain HTTP within cluster except: `GET /healthz` on `localhost:9090` (not exposed via Service).
- Linkerd proxy handles mTLS transparently — no application-level TLS code required.
- NetworkPolicy: default-deny ingress/egress; explicit allow rules per service.
- NATS TLS 1.3 minimum; nkeys replace username/password auth for all tenant connections.
- Certificate rotation: Linkerd cert-manager integration, 24h leaf cert TTL.

```

```

### Access Log Redaction Middleware (Go)

```go
// Redact Authorization header before writing access log
func redactHeaders(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        if r.Header.Get("Authorization") != "" {
            r.Header.Set("Authorization", "[REDACTED]")
        }
        next.ServeHTTP(w, r)
    })
}
```

**Rules:**
- Secrets never logged, never in environment variables of non-Vault-agent pods.
- Vault agent sidecar injects secrets as in-memory files (`tmpfs` mount).
- No secrets in Helm values files; all via `vault.hashicorp.com/agent-inject` annotations.

## 6. SSRF Prevention

### Attack Scenario

Alert label `runbook_url = "http://169.254.169.254/latest/meta-data/"` → MCP server fetches it during incident enrichment → AWS metadata exposed.

### Mitigations

| Layer | Control |
|---|---|
| paladin-ingest | Reject label values matching `(?i)^https?://` unless domain is in tenant allowlist |
| paladin-ingest | `runbook_url` validated: scheme = `https`, domain must be in `kv/v2/tenant/<id>/allowed_domains` |
| MCP server config | Integration endpoint URLs sourced exclusively from Vault (`kv/v2/integrations/<tenant>/<id>/url`) |
| MCP server runtime | HTTP client uses allowlist-only transport — rejects any URL not matching configured base |
| Kubernetes NetworkPolicy | MCP server pods: egress allowed only to explicitly whitelisted external CIDRs/domains |
| paladin-hub | Tool call parameters validated against JSON schema before execution; `url` fields type-checked and domain-verified |

### Allowlist Transport (Go Sketch)

```go
func allowlistTransport(allowed []string) http.RoundTripper {
    return roundTripFunc(func(req *http.Request) (*http.Response, error) {
        for _, a := range allowed {
            if strings.HasPrefix(req.URL.String(), a) {
                return http.DefaultTransport.RoundTrip(req)
            }
        }
        return nil, fmt.Errorf("SSRF: URL %q not in allowlist", req.URL)
    })
}
```

## 9. Incident Response

### Playbook Matrix

| Incident | Immediate Action | Recovery | Notification |
|---|---|---|---|
| Compromised tenant credentials | Revoke Vault lease for tenant path | Rotate Vault transit key → crypto-shred → regenerate credentials | Notify tenant within 1h |
| Compromised service account (K8s SA) | `kubectl delete sa <name>` → Vault revokes role | Rotate Linkerd cert (cert-manager reissue) → redeploy pod | Internal security team |

## 10. Penetration Testing Scope

**Frequency:** Annual external pen test + quarterly internal red team exercise.

| Target | Test Focus |
|---|---|
| `paladin-edge` API | JWT forgery, privilege escalation, IDOR, rate limit bypass |
| `paladin-ingest` webhook | Prompt injection payloads, oversized payloads, SSRF via runbook_url |
| NATS JetStream | Subject isolation bypass, cross-tenant subscription, nkey forgery |
| Qdrant | Tenant payload filter bypass, unauthenticated access to vector data |
| Vault | Policy misconfiguration, wildcard path abuse, token privilege escalation |
| LLM context (paladin-hub) | Prompt injection via stored memory, context poisoning across turns |
| Supply chain | Unsigned image acceptance, Helm values injection |

**Scope exclusions:** LLM provider infrastructure (OpenAI/Anthropic), customer-side collector.

**Finding SLAs:** Critical → fix within 24h | High → 7 days | Medium → 30 days | Low → next sprint.
